# SauceDemo Automation Framework

Automation framework built using:

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)
* PageFactory
* Git & GitHub

## Framework Structure

src/test/java

* base
* factory
* pages
* tests
* utils

src/test/resources

* config.properties

## Features

* Centralized configuration management using ConfigReader
* Browser initialization using DriverFactory
* Common setup and teardown using BaseTest
* Page Object Model implementation
* Reusable page methods
* TestNG-based test execution
